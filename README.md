# Vertex — login & registration design

A responsive frontend prototype built with HTML, CSS, and vanilla JavaScript. Open `dist/index.html` directly, or serve the folder with `python3 -m http.server 4173 --directory dist`.

Use the Log in / Sign up tabs or the `#login` and `#signup` URL fragments. The interface includes accessible form labels, inline validation, show/hide password controls, responsive layouts, and preview dialogs for social sign-in and recovery.

This is a design demo: accounts, sessions, social sign-in, recovery, and the remember-me preference are not connected to a backend. Form details are never transmitted, logged, or persisted. Use sample details. Google Fonts is used for typography with local sans-serif fallbacks.
